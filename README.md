# pseudotimede-py

This is a python implementation of the
[PseudotimeDE](https://github.com/SONGDONGYUAN1994/PseudotimeDE) algorithm to
test for differential expression along pseudotime trajectories in a way that
accounts for uncertainty in the pseudotime estimation phase. It uses the
[scDesigner](https://github.com/krisrs1128/scDesigner) package to accelerate
model fitting. See this
[notebook](https://github.com/krisrs1128/pseudotimede_py/blob/main/examples/lps.ipynb)
for an example application.
